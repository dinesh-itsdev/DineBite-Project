# 🍽️ DineBite

DineBite is a modern full-stack food delivery web application built with **React.js, Spring Boot, and Oracle Database**.

The application allows users to browse restaurants and food items, search for food, add items to a cart, place orders, write reviews, and receive AI-based food recommendations.

---

## 🚀 Features

- 🏠 Modern responsive home page
- 🍴 Browse restaurants and food items
- 🔍 Food search and categories
- 🤖 AI-based food recommendations
- 🛒 Shopping cart
- 📦 Order management
- ⭐ Food reviews and ratings
- 🔐 User registration and login
- 👨‍💼 Admin food management
- 📱 Responsive user interface
- 🔗 React frontend connected to Spring Boot REST APIs
- 🗄️ Oracle Database integration
